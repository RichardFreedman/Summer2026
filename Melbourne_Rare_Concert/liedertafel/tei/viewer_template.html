About this edition

        
A page-by-page TEI P5 edition of the printed programme for the Melbourne Liedertafel's 263rd concert, given in the Melbourne Town Hall on Monday 23 October 1899 under Professor G. W. L. Marshall-Hall. The left pane shows the encoded text of the page displayed on the right. Use the tabs to see the TEI source for the current page, or the whole file including its header.

        
Validated against tei_all.rng The file passes RelaxNG validation against the TEI Consortium's tei_all schema (every TEI module enabled). The validation script lives beside the file in the repository as tei/validate.py.

        
How the encoding works

        
    
          
  • Pages. Each page begins with <pb n="…" facs="#f…"/>. The n is the page's position in the digitised copy (1 to 20); the printed folio, "(1)" to "(16)", is kept separately as <fw type="pageNum">. The viewer splits the document at each pb, keeping the surrounding structure, which is why a stanza that runs over a page break appears in both pages, each holding only its own lines.
    • 
          
  • Facsimile. The <facsimile> section holds one <surface> per page with two <graphic> elements: the contrast-enhanced print version and the original colour scan. The facs attribute on each pb points at its surface.
    • 
          
  • Text-image links. Each surface carries <zone> elements with pixel coordinates (ulx uly lrx lry), and text elements point at them with facs. The coordinates came from fuzzy-matching each element's text against the line boxes in the scan's OCR layer, which is poor at reading letters but good at locating them; a few headings the OCR could not see at all are placed by position and marked type="estimated" (dashed in the viewer). Figures were located by image analysis.
    • 
          
  • Structure. The cover is a <titlePage> in <front>; the officers, orchestra and choir are <list>s; the concert programme is a <div type="programme"> divided into parts and items; sung texts are <lg>/<l> with xml:lang marking German and Scots; the printer's imprint sits in <back>.
    • 
          
  • Typography. Blackletter, copperplate script, italics, small capitals and letter-spaced faces are recorded with rendition pointers to CSS definitions in <tagsDecl>. The viewer reads those definitions from the file and applies them, so the rendering rules live in the TEI, not in this page.
    • 
          
  • Editorial handling. Spelling is as printed. Ditto marks in the orchestra list are kept and expanded with <choice><abbr>/<expan>; the toggle above switches between them. Ornaments and engravings are recorded as <figure><figDesc>; rules and dotted separators as <milestone>.
    • 
        

        
Source and transcription

        
Transcribed by reading the page images at 130 to 400 dpi; the OCR layer embedded in the digitised PDF was not usable. Six names in the choir roll are small enough in the scan to be worth checking against another source: Robie, Voight, Pincus, Whiter, Denneston, Hanify. Digitisation reference UDC20260028-21.
